# Continuidad visual · Fase 3

Se continúa la identidad de [Figma aprobado](https://www.figma.com/design/rnRXp8n6sZS7xnVa6kGgij?node-id=11-172): Literata para titulares, IBM Plex Sans para lectura y datos, IBM Plex Mono para correspondencia; papel cálido, bosque, vino, coral, sol y menta. Se preservan navegación, estructura de portada, anverso físico, pregunta, reverso limpio, barras 0–100 y álbum.

Cambios necesarios para escalar, sin rediseñar la interfaz:

- Una misma plantilla obtiene nombre, código, título, pregunta, tasas y reflexión de cada entidad.
- Jalisco conserva su ilustración aprobada. Las otras 31 postales usan una composición abstracta compartida de archivo postal, sin atribuir acontecimientos ni motivos culturales a sus territorios. No se diseñaron 31 ilustraciones individuales.
- Se activan los 32 enlaces del explorador y los estados descubierta/guardada. Se ordenan alfabéticamente; las claves oficiales se separan de los índices de colección.
- El álbum dispone varias postales en una cuadrícula de dos columnas en escritorio y una columna en móvil, manteniendo el componente de postal existente.
- El reverso incorpora anterior/siguiente, progreso y un detalle sobre porcentaje no especificado. La gráfica sigue mostrando las tres tasas originales, en orden de edad y con unidades claras.
- La advertencia estadística incorrecta del MVP se sustituye por trazabilidad: cotejo directo de las tasas con los tres originales y límites documentales explícitos.

Las comprobaciones de tamaño y las limitaciones de navegador se describen en `PRUEBAS.md`. No se afirma una auditoría visual automática píxel a píxel ni certificación WCAG. La captura del álbum actual muestra la coexistencia de varias entidades dentro del mismo sistema visual.
